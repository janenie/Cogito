# CUBICLE AREA 线索锚点调整设计

## 目标

让 `CUBICLE AREA` 的本局合同线索稳定出现在桌面上，并位于玩家面对该桌子时的右手侧，
避免当前锚点高度接近地面而导致线索难以看见。

## 设计

- 只调整 `COGITO_3_Lobby.tscn` 中
  `CUBICLE_AREA/FindContractAnchor` 的局部变换。
- 锚点放在现有桌面的桌面高度，目标局部高度约为 `y = 0.78`。
- 水平位置采用桌面右侧、略靠玩家的一处位置，并与桌边保留间距，避免线索超出桌面。
- 线索仍由 `ai_play_find_contract_terminal.gd` 在生成回合时重新挂载到该锚点；
  随机路线、随机内容、阅读交互和谜题进度规则均不改变。

## 验证

- 场景静态检查继续通过。
- Godot Lobby 集成测试继续通过。
- 启动普通 Lobby，确认线索位于桌面而非地面，且玩家面对桌子时能在右手侧直接看到并交互。
- 运行 `git diff --check`。
