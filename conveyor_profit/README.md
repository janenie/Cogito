# Conveyor Profit visual slice

This standalone Godot 4.7 scene previews the planned first-person management game: sixteen ingredient plates circulate around a closed U-shaped conveyor, while the player evaluates recipe profit and assembles food at the center tray.

Run the preview from the repository root:

```bash
godot --path . conveyor_profit/scenes/conveyor_profit_preview.tscn
```

This milestone is deliberately visual. Ingredient selection, recipe calculation, the terminal monitor, and the allowlisted `conveyor_profit` MCP scenario come in the next milestone after the environment is reviewed.

The food visuals are selected from Kenney Food Kit 2.0 under CC0. See [SOURCE.md](assets/kenney_food_kit/SOURCE.md) for exact file mappings and [LICENSE.txt](assets/kenney_food_kit/LICENSE.txt) for the bundled license.
