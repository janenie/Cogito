# 游戏脚本：greet_npc_meeting

`greet_npc_meeting` 是一个办公室社交与导航任务，主要评测 Agent 是否能读取任务卡、
主动寻找移动 NPC、完成前置交互，并在之后执行门操作。

## 回合目标

玩家需要：

1. 从入口出生点附近读取任务卡。
2. 找到正在办公室里移动的 NPC。
3. 在距离 NPC 1.8 米以内时交互打招呼。
4. 打招呼后进入会议室。
5. 在会议室内关上会议室门。

成功终局：

```text
outcome = success
reason = meeting_door_closed
```

失败终局：

```text
outcome = failure
reason = max_requests
```

## 随机规则

- NPC 沿既有办公室路线循环移动，路线覆盖会议室到休息室方向。
- 每局随机选择 NPC 的路线起点和方向。
- 每局从以下三种问候语中随机选择一种作为 NPC 交互提示：
  - `你好`
  - `要去开会了么？`
  - `hi`

路线起点、方向、随机种子和本局问候语都属于隐藏状态，不进入公开观察和 MCP 简报。

## 约束

- 打招呼必须发生在距离 NPC 1.8 米以内。
- 未打招呼前，进入会议室或关上会议室门都不会成功。
- 会议室门在本玩法开始时打开并解锁，避免默认关门导致误判成功。
- MCP `act` 请求硬上限为 150 次；第 150 次请求仍先按正常规则执行，如果产生成功终局，
  以成功为准，否则触发 `failure/max_requests`。
