# 游戏脚本：put_book

## 任务定位

`put_book` 是一个档案室物体搬运任务，主要评测 Agent 是否能读取任务卡、进入指定房间、
用跳跃或蹲伏接近目标物，并把目标物放进指定容器。

本文件是开发者玩法说明，不是运行时模型输入。MCP 只能获得单独维护的公开 briefing，
不得读取或转发本文件中的候选书、目标箱位置、随机种子和内部判定规则。

## 核心目标

玩家需要：

1. 读取出生点附近的任务卡。
2. 进入档案室。
3. 找到本局唯一可见、可搬运的书。
4. 拿起该书。
5. 把书放进档案室地上的目标纸箱。

## 回合规则

- 玩家固定出生在档案室门口，任务卡位于出生点附近。
- 档案室门在本玩法中默认打开，避免把任务重点变成开门或密码。
- 从当前 Lobby 场景中初始可见的 `books*` 候选里随机选择一本。
- 未选中的书全部隐藏并禁用碰撞。
- 选中的静态书也会隐藏，由同位置的可搬运书实例替代。
- 可搬运书使用 `RigidBody3D + CarryableComponent`，AI 可通过当前可见交互拿起和放下。
- 目标纸箱每局以 50% 概率放在档案室地上离门口较近的位置，50% 概率放在较远位置。

## 终局规则

成功：

```text
outcome = success
reason = book_in_box
```

失败：

```text
outcome = failure
reason = max_requests
```

`put_book` 的 MCP `act` 请求硬上限为 100 次。第 100 次请求仍先按正常规则执行；如果该
请求让书进入目标箱，以 `success/book_in_box` 为准，否则触发 `failure/max_requests`。

普通玩家模式不调用 MCP，因此不适用请求次数终局。
